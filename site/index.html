Ouvrir le projet sur GitHub ↗
INSTALLATION LOCALE
git clone https://github.com/renaud-bxl/prosper-et-les-prospects.git
cd prosper-et-les-prospects
npm ci
npm start

Le QG s’ouvre dans votre navigateur. Commencez par une ville et cinq commerces.

Les mails sont-ils envoyés automatiquement ?

Non. Prosper prépare des brouillons. Vous décidez de leur contenu et de leur utilisation. L’envoi se fait depuis votre messagerie, après avoir vérifié les règles applicables à votre situation.
